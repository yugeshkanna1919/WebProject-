# Frontend Documentation for MERN App

## Overview
This is the frontend part of the MERN stack application. It is built using React and communicates with the backend to provide a seamless user experience.

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Installation
1. Navigate to the frontend directory:
   ```
   cd mern-app/frontend
   ```

2. Install the dependencies:
   ```
   npm install
   ```

### Running the Application
To start the development server, run:
```
npm start
```
This will start the application on `http://localhost:3000`.

### Folder Structure
- `src/`: Contains all the source code for the frontend application.
  - `components/`: Contains reusable React components.
  - `pages/`: Contains the different pages of the application.
  - `index.js`: The entry point of the React application.
  - `App.css`: Contains styles for the application.

## Usage
Once the application is running, you can navigate to the home page to view the application in action. The frontend interacts with the backend API to fetch and display data.
